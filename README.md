# 사과 게임

<p align="center">사과 게임 레포지토리입니다.</p>

## Introduction

<p>심심할 때 사과 게임을 종종 하는데, 기존 사과 게임은 모바일 웹으로 하기 환경이 불편해서 만들어본 프로젝트입니다.</p>
<p>합쳐서 사과의 숫자의 합이 10이 되면 점수를 얻는 간단한 게임입니다.</p>
